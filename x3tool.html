🦈 ATTACK SHARK X3 — HID Config Tool

WebHID reverse-engineering helper · VID 0x1d57 PID 0xfa61 · config interface 2 (usage 0x01/0x80) · Feature Report 0x04 (51-byte payload)

How to use

1) Serve this file over localhost (WebHID needs a secure context): e.g. python -m http.server 8000 then open http://localhost:8000/x3tool.html in Chrome or Edge.
2) Click Connect and pick the "USB Gaming Mouse".
3) Paste captured Wireshark SET_REPORT payloads into the capture slots (one per experiment) and press Compare — it highlights exactly which bytes changed between captures.
4) Use the DPI scanner to find the DPI field, then edit bytes in the config editor and press Send to test a hypothesis (only after you have enough differential evidence!).
Reads (receiveFeatureReport) may time out on this device — that's expected; writes are the reliable path.

DPI writer

Encodes DPI the way the firmware does: stage byte = DPI/50 − 1 at offset 7+stage (stage 5 also sets the carry byte at 20), then fixes the checksum. DPI must be a multiple of 50.

Decoded report

Interprets the current editor payload using the decoded protocol (report 0x04 / 0x05 / 0x06).

DPI / numeric field scanner

Scans the current editor payload for every little-endian u16 / u32 in the X3 DPI range (50–26000, step 50). Click a row to select that byte range in the editor.

Persistence

Slots, editor and report ID auto-save to localStorage. You can also export/import everything as JSON.
